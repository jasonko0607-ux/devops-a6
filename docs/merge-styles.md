# Merge Styles

| Style | History shape | When to use |
| --- | --- | --- |
| Merge commit | Keeps the branch and adds a merge commit | Long-lived or release branches |
| Squash and merge | One commit per PR | Small feature PRs |
| Rebase and merge | Linear, keeps every commit | When every commit passes CI |
| Fast-forward | Linear, no new commit | Local merges outside PRs |
